# QA Automação de Dados

Projeto prático de automação de dados utilizando 8n e APIs REST.

## Tecnologias
- Git e GitHub
- JavaScript e Node.js
- APIs REST
- n8n
- SQL
- Engenharia de Dados

## Objetivo
Construir uma automação que consome dados de uma API,
transforma as informações e organiza os resultados.
